## 🧪 Convenciones / Conventions

**ES:** Los scripts independientes se ejecutan con `tclsh9.0`. Los proyectos tipo librería separan `src/` y `test/`, registran paquetes con `pkgIndex.tcl` y usan Tcltest para las pruebas.

**EN:** Standalone scripts run with `tclsh9.0`. Library-style projects separate `src/` and `test/`, register packages with `pkgIndex.tcl`, and use Tcltest for testing.
